# Contributing

Scenes, sound styles and fixes are welcome.

- **One scene per pull request**, written to [SCENE-SPEC.md](SCENE-SPEC.md). Include the output of `npm run check -- <CompositionId>` and commit the still from `npm run stills -- <CompositionId>`.
- **Gates are not negotiable.** A PR that loosens `verify-layout` or `verify-sound`, or edits the safe-zone tokens, to make a scene pass will not be merged.
- **Synthesised sound only.** Every sound must be generated by `scripts/make-sfx.mjs`; recorded samples cannot be relicensed as MIT. A new style is a module in `scripts/lib/styles/` plus a row in `TARGETS` in `scripts/verify-sound.mjs`.
- Keep scene modules React-free and deterministic.
- Run `npm run typecheck` before pushing.
